Сайт-приглашение на свадьбу — Сергей и Людмила

Что внутри:
- адаптивный сайт-приглашение под телефон и компьютер;
- дата: 27 июня;
- ЗАГС/роспись: 10:00, Дворец торжеств, Сургут, бульвар Свободы, 5;
- ресторан: 16:00, La Storia, Сургут, ул. Энтузиастов, 44а;
- форма RSVP сохраняет ответы гостей;
- скрытая страница администратора admin.html показывает, кто придёт, кто не сможет и сколько гостей всего;
- есть экспорт списка гостей в CSV;
- можно удалить ошибочный ответ из админки;
- локально ответы сохраняются в data/rsvp.json;
- на хостинге можно подключить PostgreSQL через переменную DATABASE_URL.
- кнопка “Добавить в календарь” скачивает файл sergey-lyudmila-wedding.ics;
- ссылка на админку убрана с главной страницы, открыть её можно по прямому адресу /admin.html.

Как запустить локально:
1. Распакуйте архив.
2. Откройте папку проекта в терминале.
3. Выполните команды:
   npm install -g pnpm
   pnpm install
   pnpm dev
4. Откройте сайт: http://localhost:3000
5. Админка: http://localhost:3000/admin.html

Пароль администратора по умолчанию:
2706

Как поменять пароль:
- локально можно запустить так:
  ADMIN_PASSWORD=ваш_пароль pnpm dev
- на хостинге добавьте переменную окружения ADMIN_PASSWORD.

Как залить на Render:
1. Создайте новый репозиторий на GitHub.
2. Загрузите в репозиторий все файлы из этой папки.
3. Откройте Render -> New -> Web Service.
4. Подключите GitHub-репозиторий.
5. Build Command: npm install
6. Start Command: npm start
7. Environment Variables:
   ADMIN_PASSWORD=любой_свой_пароль
8. Для надёжного хранения ответов подключите PostgreSQL и добавьте переменную DATABASE_URL.
   В архиве уже есть render.yaml — Render может создать Web Service и базу по Blueprint.

Важно про сохранение ответов:
- Если сайт открыт двойным кликом как index.html, форма не сможет сохранять ответы.
- Для сохранения нужен сервер: локально pnpm dev, на хостинге Node.js Web Service.
- На бесплатном Render файловая система может сбрасываться при перезапуске/деплое, поэтому для реального сбора гостей лучше использовать PostgreSQL через DATABASE_URL.

Что можно быстро поменять:
- Дату и время: в index.html найдите "27 июня", "10:00" или "16:00".
- Адрес церемонии: найдите "Дворец торжеств" или "бульвар Свободы, 5".
- Время банкета: блок с id="program", пункт "Праздничный ужин в La Storia".
- Цвета свадьбы: блок class="palette" и текст в блоке "Дресс-код".
